# Feedly's Complete CTI Prompt Library

Every prompt published across four Feedly TI Essentials posts, gathered into one folder. Each prompt is a separate markdown file with its prompt text plus context on what it does, which report it came from, and the workflow it supports.

44 prompts across 4 source reports.

## How the numbering works

Every file is prefixed with a report code and a sequence number, so you always know which resource a prompt came from:

- **R1** = CTI Prompt Library (Volume 1)
- **R2** = CTI Prompt Library (Volume 2)
- **R3** = How to Automate Common CTI Workflows
- **R4** = Accelerating BFSI CTI Workflows with Prompt-Driven Threat Intelligence

For example, `R2-05-detection-rule-to-splunk-spl-converter.md` is the 5th prompt from Report 2.

## File format

Each prompt file contains:
- Title, source report, source URL, and the section/workflow it appeared under
- "What this prompt does": context on the use case
- "Prompt": the prompt text (placeholders preserved exactly)
- "Notes": tips, variations, or expected output where the article provides them

Prompt text follows the source posts, with obvious typos corrected and placeholders preserved exactly.
