# Mappings file schema (mappings.json)

`scripts/attack_tool.py` reads this file for `verify-quotes`, `build-layer`,
`build-comparison-layer` and `export-stix`.

```json
{
  "layer_name": "APT-X Vendor Report TTP Mapping",
  "description": "Behaviour from <report> mapped to ATT&CK <version>.",
  "sources": [
    {"id": "1", "title": "<report title>", "url": "https://...",
     "published": "YYYY-MM-DD", "text_path": "source-1.txt", "reliability": "B2"}
  ],
  "attack_version": "19.2",
  "verification_status": "Verified against both sources",
  "version_checked": "YYYY-MM-DD",
  "min_confidence": "low",
  "parent_highlight": "none",
  "include_rationale_in_comments": true,
  "generated_by": "map-attack-techniques skill. Model-made claims: review each mapping against its quotes before distribution.",
  "source_cited_ids": ["T1059.001", "T1566.002"],
  "reconciliation": [
    {"id": "T1059.001", "disposition": "Current, retained"},
    {"id": "T1566.002", "disposition": "Not supported by the narrative"}
  ],
  "mappings": [
    {
      "ref": "1",
      "domain": "enterprise",
      "technique_id": "T1566.001",
      "technique_name": "Spearphishing Attachment",
      "tactic": "initial-access",
      "confidence": "high",
      "occurrence": "observed",
      "procedure": "One to two sentences, as in section 1.",
      "quotes": [
        {"text": "Exact verbatim sentence from the source.", "locator": "Section 2, paragraph 3", "source_ref": "1"},
        {"text": "A second supporting passage [...] with an omission marked.", "locator": "Page 4"}
      ],
      "rationale": "One or two sentences, used in the cell comment.",
      "paired_with": ""
    }
  ]
}
```

## Fields

- `sources[].text_path`: the plain-text copy saved in Step 0. Without it,
  quote verification reports NOT CHECKED. `published` is used to flag
  techniques created in ATT&CK after the source date.
- `sources[].id`: a string or number; quotes point to it with
  `source_ref`. `sources[].reliability`: optional Admiralty grade (for
  example "B2"), only when the user gives one. It is written to the layer
  metadata and section 0.
- `attack_version`: the version decided in Step 2. All domains use the
  same version number.
- `min_confidence`: "low", "moderate" or "high", from Q5. Include
  below-threshold mappings in `mappings` anyway: the script filters them out
  of the layer, and section 5 keeps their record.
- `parent_highlight`: always "none" (parent left uncoloured, only expanded).
- `include_rationale_in_comments`: false when the user chose no rationale.
- `generated_by`: text for the layer's "generated by" metadata field. Keep
  the default unless the user wants their own wording for external
  distribution.
- `source_cited_ids`: every distinct ATT&CK ID the source cites, or `[]` if
  none. Leaving it out makes the reconciliation check NOT CHECKED.
- `reconciliation`: one entry per cited ID. `disposition` must begin with
  one of the section 2 statuses (for example "Revoked (replaced by
  T1685.005)"). The script fails the build if an ID is missing, repeated or
  not cited, or if a disposition is empty or not a section 2 status.
- `mappings[].ref`: the row number in section 1 after sorting, so the layer
  and the report can be read side by side. Below-threshold mappings take
  refs "B1", "B2" and so on, matching section 5. Refs must be unique.
- `mappings[].domain`: "enterprise", "ics" or "mobile". If left out, T0###
  IDs are treated as ICS and everything else as Enterprise.
- `mappings[].confidence`: "high", "moderate" or "low" ("medium" is accepted
  and treated as "moderate").
- `mappings[].occurrence`: "observed", "reported", "source-assessed" or
  "capability-only". Required.
- `mappings[].quotes`: one or more objects. `text` and `locator` are
  required. `source_ref` points to `sources[].id` and defaults to the first
  source. Mark omissions with `[...]`. Each quote needs at least four words.
  The script matches quotes word for word, on word boundaries, after
  normalising whitespace, curly quotes and dash characters.
- `mappings[].paired_with`: the `ref` of the other row when one behaviour is
  deliberately mapped in two domains (decision rule R4). The build fails if
  it names a ref that does not exist.

Schema v1 files (one `quote` string and one `source` string per mapping) are
still read, but `occurrence` is now required.

For one layer per source, write one mappings file per source. For several
domains, use one mappings file and run `build-layer` once per domain with
`--domain`.

## F. feedly-context.json (Step 8 only)

`build-comparison-layer` reads this file together with `mappings.json`.

```json
{
  "query_date": "2026-10-02",
  "window": {"start": "2025-10-02", "end": "2026-10-02"},
  "entities": [
    {
      "source_name": "APT29",
      "source_locator": "Executive summary, para 1",
      "attribution": "attributed by source",
      "feedly_entity": "APT29",
      "match_basis": "exact name"
    }
  ],
  "profile": [
    {
      "entity": "APT29",
      "technique_id": "T1566.001",
      "tactic": "initial-access",
      "domain": "enterprise",
      "article_count": 14,
      "feedly_id_original": null,
      "articles": [
        {"title": "...", "publisher": "...", "date": "2026-09-14", "url": "https://..."}
      ]
    }
  ],
  "not_comparable": []
}
```

- `profile[].entity` must match an `entities[].feedly_entity`.
- `profile[].technique_id` is the current ID after `lookup`. If Feedly gave
  a revoked ID, put the original in `feedly_id_original`.
- `profile[].tactic` is optional. If left out, the script uses the mapped
  tactic(s) when the technique is also mapped, and otherwise every tactic
  the technique sits under in the pinned bundle.
- `profile[].article_count` is after deduplication (source and
  republications removed, same-publisher campaign reporting counted once).
- `profile[].domain` defaults as for mappings (T0### is ICS).
- `entities[].attribution`: "attributed by source", "attributed by third
  party cited in source", or "suspected or tentative".

`build-comparison-layer` reads `mappings.json` for the mapped techniques
and confidence threshold, assigns groups, checks ATT&CK content against the
pinned bundle as `build-layer` does, and prints a check report. Quote
verification and source ID reconciliation do not apply to this layer and
are reported as NOT APPLICABLE, not NOT CHECKED. "Not in this report"
techniques need at least two articles to appear in the layer (top 25 per
entity, by article count); the rest are counted in the report only.
